coding style

i follow very strict rules when it comes to styling my c code,
in this section i'll explain my rules.
my .clang-format 
            
BasedOnStyle: LLVM

IndentWidth: 4
TabWidth: 4
UseTab: Never

BreakBeforeBraces: Allman

AllowShortFunctionsOnASingleLine: None
AllowShortIfStatementsOnASingleLine: Never
AllowShortLoopsOnASingleLine: false

ColumnLimit: 100

i try to use the file but not sure if nvchad uses it correctly...

explaining my .clang-format

option value description
BasedOnStyle LLVM uses llvm as the base formatting style
IndentWidth 4 sets indentation to four spaces
TabWidth 4 sets tab width to four columns
UseTab Never always uses spaces instead of tab characters
BreakBeforeBraces Allman places opening braces on a new line
AllowShortFunctionsOnASingleLine None prevents functions from being placed on a single line
AllowShortIfStatementsOnASingleLine Never prevents short if statements from being placed on a single line
AllowShortLoopsOnASingleLine false prevents short loops from being placed on a single line
ColumnLimit 100 limits lines to 100 columns

i feel like the .clang-format works for me, i know it's not the best; but it works!
